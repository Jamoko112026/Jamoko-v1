# JaMoKo Changelog

Alle wichtigen Änderungen an JaMoKo werden hier ruhig und nachvollziehbar
dokumentiert.

## 2026-07-03

### Hinzugefügt
- Projektleitfaden `AGENTS.md` erstellt.
- Entscheidungsregel für verständliche, wartbare Lösungen ergänzt.
- Schema.org-Daten für JaMoKo, Startseite, Angebot und Kontaktseite ergänzt.
- `ROADMAP.md` und `CHANGELOG.md` im Dokumentationsordner erstellt.

### Geändert
- Hero der Startseite vereinfacht.
- Nutzen, Zielgruppe und nächster Schritt im Hero klarer formuliert.
- Haupt-CTA auf kostenloses Erstgespräch ausgerichtet.
- Trust-Elemente im Hero erweitert.

### Geprüft
- `npm run lint`
- `npm run build`

## Dokumentationsregel
Neue Einträge sollen kurz, klar und verständlich bleiben.

Bevorzugt:
- was geändert wurde
- warum es geändert wurde
- was geprüft wurde

Vermeiden:
- lange interne Erklärungen
- unklare Sammelbegriffe
- übertriebene Erfolgsaussagen
