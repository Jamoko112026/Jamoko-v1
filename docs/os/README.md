# JaMoKo OS 1.0

JaMoKo OS ist das Betriebssystem hinter JaMoKo.

Es beschreibt, wie JaMoKo als professionelle kleine Agentur arbeitet:
ruhig, klar, nachvollziehbar und nachhaltig.

Dieses System soll nicht starr machen.
Es soll helfen, gute Entscheidungen wiederholbar zu machen.

## Zweck

JaMoKo OS gibt Orientierung für:

- Entscheidungen
- Vertrieb
- Projekte
- Gestaltung
- Entwicklung
- SEO
- Qualität
- Kundenbeziehungen
- Finanzen
- Wissen
- Wachstum

## Grundprinzip

Nicht lauter machen.

Klarer machen.

## Checkliste

- Passt die Entscheidung zur JaMoKo-Haltung?
- Wird etwas verständlicher?
- Wird Vertrauen gestärkt?
- Bleibt die Lösung wartbar?
- Hilft es dem Besucher?
- Hilft es dem Unternehmen?

## Was wir vermeiden

- Aktionismus
- Agentur-Floskeln
- unnötige Komplexität
- unklare Verantwortlichkeiten
- Wachstum um jeden Preis
