# JaMoKo Coding Style

Code soll ruhig, klar und wartbar bleiben.

## Grundregeln
- Next.js App Router verwenden
- TypeScript beibehalten
- bestehende Komponenten wiederverwenden
- Tailwind-Konzept beibehalten
- keine neuen Libraries ohne klaren Grund
- semantisches HTML nutzen
- Barrierefreiheit mitdenken

## Bestehende Stärken erhalten
- klare Komponentenstruktur
- verständliche Benennung
- saubere TypeScript-Struktur
- einheitliche Tailwind-Nutzung
- schnelle Build-Zeit

## Entscheidungen
Nicht die cleverste Lösung gewinnt, sondern die verständlichste und am besten
wartbare Lösung.
