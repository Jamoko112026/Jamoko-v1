# JaMoKo SEO

SEO soll Klarheit unterstützen, nicht Sprache aufblasen.

## Jede wichtige Seite braucht
- eindeutigen Meta Title
- eindeutige Meta Description
- genau eine H1
- logische H2-Struktur
- interne Links
- sinnvolle Alt-Texte
- saubere Canonical-URL
- passende strukturierte Daten, wenn sinnvoll

## Inhaltlicher Fokus
Die wichtigsten Suchsignale sind:
- Mini-Websites
- lokale Betriebe
- Handwerker
- Dienstleister
- Hamburg und Deutschland

## Entscheidungen
SEO-Änderungen müssen Menschen zuerst helfen. Keywords dürfen die Sprache nie
unnatürlich machen.
