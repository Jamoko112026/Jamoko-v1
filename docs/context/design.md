# JaMoKo Design

Das bestehende Design ist ruhig und soll erhalten bleiben.

## Farben
- Deep Navy `#001821`
- Gold `#E5C58B`
- Teal Green `#1AC7A4`

## Stil
- klar
- hochwertig
- organisch
- nicht überladen
- gut lesbar

## Vermeiden
- unnötige Animationen
- grelle Effekte
- komplette Redesigns ohne Auftrag
- dekorative Elemente ohne Nutzen

## Entscheidungen
Designänderungen sind nur sinnvoll, wenn sie Verständlichkeit, Vertrauen,
Lesbarkeit oder Kontaktaufnahme verbessern.
