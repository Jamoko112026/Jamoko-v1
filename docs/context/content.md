# JaMoKo Content

Texte sollen schnell erklären, worum es geht.

## Sprache
- Deutsch
- einfach
- klar
- persönlich
- konkret

## Gute Inhalte beantworten
1. Was ist das Angebot?
2. Für wen ist es?
3. Warum ist es vertrauenswürdig?
4. Was ist der nächste Schritt?

## Bevorzugte Wörter
- ruhig
- klar
- verständlich
- lokal
- persönlich
- ehrlich

## Entscheidungen
Ein Text ist gut, wenn er nach drei Sekunden mehr Klarheit schafft als vorher.
